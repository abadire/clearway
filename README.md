# Clearway Docreader

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 21.0.5.

## Development server

```bash
pnpm run dev
```

Документы открываются по названию папки в которой они расположены. В данном случае - http://localhost:4200/test%20doc

## Известные проблемы

- Нет определения пересечений аннотаций. Решение - определить требования по пересечениям
- Нет менять текст аннотаций, размер, цвет
- Не учтен вариант когда пользователь рисует аннотацию и выводит угол прямоугольника за границу канваса или перетаскивает аннотацию за границу канваса. Решение - добавить обработчики mouseleave и mouseenter с определением зажата ли кнопка мыши у пользователя при возвращении в канвас
- Невозможно удалить аннотацию чей крестик расположен за границами канваса без предварительного перетаскивания. Решение - рисовать крестик в том углу аннотации, который расположен достаточно далеко от границы канваса
- Код который учитывает масштаб при работе с аннотациями довольно сложный и размазанный, по хорошему надо завернуть его в абстракцию
